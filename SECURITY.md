# Security

impactite is a server that holds accounts, sessions and the stats of every site on it.

If you find something real (e.g. a way to read another site's stats, get past sign-in, or run code on the server), please don't open a public issue. Report it through [GitHub security advisories](https://github.com/Z1xus/impactite/security/advisories/new) or contact me directly at [z1x.us](https://z1x.us/), or [hi@z1x.us](mailto:hi@z1x.us) if you prefer email.

Fixes only go into the latest release.

Thank you for being responsible.
